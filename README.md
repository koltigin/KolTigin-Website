# KolTigin

Public site for [koltigin.xyz](https://koltigin.xyz/). Static HTML, CSS, and JavaScript, hosted on GitHub Pages.

English is the default language. Turkish is a manual choice stored in the browser.

## Local preview

```bash
python3 -m pip install pyyaml
python3 scripts/generate-projects.py
python3 scripts/generate-writings.py
python3 scripts/admin-dev-server.py
```

Open `http://127.0.0.1:3000`.

## Content updates

Edit Markdown and JSON in this repository. See [CONTENT-MAINTENANCE.md](./CONTENT-MAINTENANCE.md). Ordinary content work does not require changing renderer JavaScript.

Projects are one Markdown file each under `content/projects/`. Category order lives in `config/project-categories.json`. `projects/projects.json` is generated by `scripts/generate-projects.py`. `content/index.json` is generated by `scripts/generate-writings.py`. Do not edit the generated JSON files.

## Customize the fallback author identity

Fallback Writing covers and generated 1200×630 social-preview images both read the same two fields in `config/site.json`:

1. **Author / site name:** `displayName`
2. **Avatar image:** `avatar` — a local path such as `./assets/images/profile/your-photo.png`

Put the replacement photo under `assets/images/profile/` (or another path you set in `avatar`). Use a **square** PNG, JPEG, or WebP. Keep faces and important detail away from the extreme edges; the image is shown as a circle.

You do **not** need to edit `scripts/generate-share.py`, fallback HTML, or generated PNGs. After you change `displayName` / `avatar` (or replace the image file), rerun the normal local or GitHub Action generator (`python3 scripts/generate-share.py` locally, or save in Admin so production regenerates). Fallback cards on the Writings page and new social-preview fallbacks update from that config automatically.

### Cover sizes

- **Your Writing cover (optional):** create this yourself. Recommended source **1600×900** (16:9). Stored with the writing, for example under `assets/images/blog/`.
- **Social preview:** generated automatically at **1200×630**. Do not hand-make the 1200×630 fallback; the project rasterizes custom covers or draws the approved identity fallback.
