# Content maintenance

GitHub is the source of truth. Edit the files below, commit, and GitHub Pages will serve the update. Ordinary content updates should not require editing renderer JavaScript.

English is the site default. Turkish is selected with the EN | TR control. The choice is stored in `localStorage` (`siteLang`). Do not add `/en/` or `/tr/` URLs; both languages share `https://koltigin.xyz/`.

## Profile, social URLs, avatar, Worker, SEO

File: `config/site.json`

- Display name, motto, avatar, email, WhatsApp, social URLs
- Worker endpoint (`contact.endpoint`) and map embed URL
- GitHub owner / repo / branch for the Last Update label
- Localized tagline and location: `{ "en": "...", "tr": "..." }`
- Localized SEO: `seo.en` and `seo.tr` (`title`, `description`)
- Canonical URL and social image path: `canonicalUrl`, `ogImage`

Replace the avatar at `assets/images/profile/profile.jpg`, or change `avatar`.

Replace the Open Graph / Twitter image at `assets/images/common/og-image.png` if the sharing card should change.

## UI labels

- English: `i18n/en.json`
- Turkish: `i18n/tr.json`

Interface strings only. Do not put article or resume paragraphs here.

## About

- English: `content/about/en.md`
- Turkish: `content/about/tr.md`

Keep the `icon:` line under each `###` service heading.

## Resume

- English: `content/resume/en.md`
- Turkish: `content/resume/tr.md`

Keep the heading structure (Summary / Experience / Education / Focus / Tools, or the Turkish equivalents).

## Projects

One Markdown file per project under `content/projects/`. Those files are the source of truth.

```
content/projects/built-by-me/
content/projects/mainnet/
content/projects/depin/
content/projects/defi/
content/projects/completed-testnets/
content/projects/completed-defi-ecosystem/
```

`projects/projects.json` is generated. Do not edit it.

Category order is configured only in `config/project-categories.json` (not alphabetical). The Projects pills and page sections both read that file, so they stay in the same order:

1. Built by Me
2. Mainnet
3. DePIN
4. DeFi & Ecosystem
5. Completed Testnets
6. Completed DeFi & Ecosystem

Empty non-archive categories stay hidden. Set `"accordion": true` on a category in `config/project-categories.json` to treat it as an archive: it stays in the navigation even when empty, and it starts collapsed. That flag currently applies to Completed Testnets and Completed DeFi & Ecosystem.

### Adding a project

1. Choose the correct category folder.
2. Create a new `.md` file (GitHub → Add file → Create new file is enough).
3. Copy `content/projects/_template.md`.
4. Fill `name`, `category`, `status`, and any optional fields you need.
5. Put the logo in `assets/images/projects/` and set `logo`.
6. Commit. GitHub Actions regenerates `projects/projects.json` and GitHub Pages deploys.

Locally you can run:

```bash
python3 -m pip install pyyaml
python3 scripts/generate-projects.py
```

### Editing a project

Edit only that project's Markdown file, then commit. Do not edit `projects/projects.json`.

### Removing a project

Delete that Markdown file, then commit. Do not edit `projects/projects.json`.

### Front matter

Required: `name`, `category`, `status` (`active`, `completed`, or `built`).

Optional: `id`, `role` (string or `{en, tr}`), `former_name`, `logo`, `summary.en` / `summary.tr`, `links` (`label`, `url`, optional `guide`), `referral_url`, `referral_code`.

Links stay an open list. Do not collapse them to a fixed Website/GitHub/Explorer set.

Projects inside a category sort A–Z by display name automatically.

Replace logos under `assets/images/projects/`.

## Articles and technical notes

Separate files per language, same basename (this basename is the shared content ID):

- `content/articles/en/` and `content/articles/tr/`
- `content/notes/en/` and `content/notes/tr/`

`content/index.json` is generated by `scripts/generate-writings.py`. Do not edit it. Locally:

```bash
python3 scripts/generate-writings.py
```

The local admin prototype runs this generator after a successful Save. A file that is not on disk will not appear. Covers go in `assets/images/blog/`.

## X posts

Add Markdown under `content/social/en/` and `content/social/tr/` with the **same filename**. Use `externalUrl` in front matter to open X. The generator lists them in `content/index.json` automatically.

## Videos

Keep one Markdown file per video in `content/videos/`. `scripts/generate-writings.py` also lists videos in `content/index.json`. Do not duplicate the 36 files.

Add bilingual titles in front matter:

```yaml
title: "Original title"
title_tr: "Turkish title"
title_en: "English title"
youtubeId: "..."
youtubeUrl: "https://youtu.be/..."
date: "YYYY-MM-DD"
```

Do not duplicate the 36 files.

## Guides

`guides/{id}/EN.md` and `guides/{id}/TR.md`. The global EN | TR control chooses the file. Point a project link at `"guide": "{id}"`.

## Production files that are not everyday content

- `CNAME` — GitHub Pages custom domain (`koltigin.xyz`)
- `robots.txt` and `sitemap.xml`
- `404.html`

## What you should not need to edit

`assets/js/*` parsers, layout CSS, and the Cloudflare Worker — unless you are changing behavior, not content. Never commit API keys, SMTP passwords, or Worker secrets.
